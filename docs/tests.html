📝 Tests Module

Comprehensive exams attached to the Course level. Designed for grading and point accumulation.

امتحانات جامع در سطح دوره؛ طراحی شده برای نمره‌دهی و کسب امتیازهای کلی.

🛠 Key Features

  • Points: Successful tests award numeric points to UserPoint history.
  • Labels: Results are labeled "Excellent", "Good", "Fair", or "Failed".
  • Files: Tests can have an associated file (PDF/JSON) stored in Vercel Blob.

🚀 API Routes

POST /tests

Creates a Test with optional testFile and picture uploads.

POST /tests/submit

Submits exam answers. Backend calculates percentage and awards proportional points.
