🧩 Quizzes Module

Short knowledge checks directly tied to Lessons. Primary goal: User verification & Badges.

کوییزهای کوتاه برای سنجش یادگیری در انتهای هر درس؛ هدف اصلی اعطای نشان افتخار است.

🛠 Internal Structure

Quiz → QuizQuestion → QuizAnswer

  • Types: multiple_choice, true_false, drag_drop.
  • Outcome: If successful, high likelihood of awarding a Badge.

🚀 API Routes

POST /quizzes/submit

Submits answers for a specific user and quiz. Logic checks score against passing requirements.

{
  "userId": 1,
  "quizId": 10,
  "answers": [
    { "questionId": 101, "answerId": 501 }
  ]
}

GET /quizzes/course/:courseId

Fetches all quizzes belonging to lessons within a specific course.
