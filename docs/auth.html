🔐 Auth & Identity

Manages User accounts, secure Login (JWT), and Social ID providers (Google/Apple).

مدیریت حساب‌های کاربری، ورود امن با توکن JWT و ورود با گوگل و اپل.

🚀 API Routes

POST /users/users

Registration route with Joi validation (Username, Email, Password, Age).

POST /users/login

Traditional login. Returns a JWT signed with user metadata.

GET /users/auth/google

Triggers Passport.js Google Strategy for OAuth 2.0 flow.

👤 User Profile Relations

  • Points: Cumulative from UserPoint
  • Time: Sum of totalActivityTime (calculated from ActivityLogs)
  • Badges: Collection in UserBadge
  • Certificate: Generated upon Course completion.
