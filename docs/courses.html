📚 Courses Module

The core container for all educational content. Courses handle meta-information and organization.

ماژول اصلی برای مدیریت دوره‌های آموزشی، اطلاعات مربی و دسته‌بندی‌ها.

🛠 Relations

  • Lessons: 1-to-Many (Course has many CourseLesson)
  • Tests: 1-to-Many (Course has many CourseTest)
  • Quizzes: 1-to-Many (Course has many CourseQuiz)
  • History: Tracks user views via CourseHistory

🚀 Primary Routes

GET /courses/courses

Fetches all courses including trainer info, pictures, and subjects.

دریافت لیست تمامی دوره‌ها همراه با اطلاعات مربی و تصاویر.

POST /courses/courses

Creates a new course. Inputs using Multipart/Form-Data.

{
  "name": "Course Title",
  "subject": "Programming",
  "file": (Image Binary),
  "trainer": "Ali Noori"
}

POST /courses/courses/duplicate/:id

Deep-clones a course and all its lessons into a new entry.

کپی کامل یک دوره همراه با تمامی درس‌های زیرمجموعه آن.
