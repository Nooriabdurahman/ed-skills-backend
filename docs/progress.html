📈 Progress & Tracking

Monitors user activity and course completion status. Crucial for the "Student Dashboard".

رهگیری پیشرفت کاربر و وضعیت تکمیل دوره‌ها؛ حیاتی برای داشبورد دانشجو.

🛠 How Progress Works

Every time a lesson is finished, a record is created or updated in CourseProgress.

  • Calculation: Percentage = (Finished Lessons / Total Lessons) * 100.
  • Upsert: Logic ensures no duplicate records for the same User + Lesson pair.

🚀 API Routes

POST /courses/progress

Marks a specific lesson as completed for the user.

{
  "userId": 1,
  "lessonId": "uuid-here"
}

GET /courses/progress/:userId

Fetches the full list of completed lessons for a user to render progress bars.
