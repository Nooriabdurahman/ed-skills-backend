🎥 Lessons Module

Managed via CourseLesson model. Holds the actual learning materials (Video, Text, Files).

ماژول مدیریت درس‌ها؛ شامل محتوای متنی، ویدیو و فایل‌های ضمیمه.

🛠 Relations

  • Course: Belongs to Course (N-to-1)
  • Quiz: Has 1 optional Quiz (1-to-1)
  • Test: Has 1 optional Test (1-to-1)
  • Progress: Used in CourseProgress to track completion.

🚀 Primary Routes

GET /courses/courses/:courseId/lessons

Fetches all lessons for a specific course including their Quiz/Test status.

دریافت لیست درس‌های یک دوره خاص همراه با وضعیت کوییز و تست آن‌ها.

POST /courses/courses/:courseId/lessons

Creates a new lesson. Supports Video and File uploads to Vercel Blob.

{
  "name": "Introdution to JS",
  "content": "Full lesson context...",
  "video": (Binary MP4),
  "file": (Binary Attachment)
}
